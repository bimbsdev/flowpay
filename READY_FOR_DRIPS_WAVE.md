## 🔐 GitHub Token Guide

### Getting a Token (2 minutes):

1. **Go to:** https://github.com/settings/tokens/new
2. **Name it:** "FlowPay Drips Wave"
3. **Select scope:** `repo` only ✓
4. **Expiration:** 90 days
5. **Generate and copy**

### Using Token Safely:

```bash
# Method 1: Direct (less safe)
python3 scripts/create-issues.py ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxx

# Method 2: Environment variable (safer)
export GITHUB_TOKEN=ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxx
python3 scripts/create-issues.py $GITHUB_TOKEN

# Method 3: GitHub CLI (most secure)
gh auth login
# (Token stored securely)
```
